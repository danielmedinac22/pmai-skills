# Other skills

Skills that are useful to the same reader but are not part of the evals loop. They are not in the plugin, so install them one by one.

| Skill | What it does |
|---|---|
| [`animate-illustration`](animate-illustration/) | Turns a static explainer illustration into a looping MP4 and GIF for LinkedIn, decks and READMEs. |

## Install one

Copy the skill folder into your skills folder. For Claude Code:

```
npx degit danielmedinac22/pmai-skills/other/animate-illustration ~/.claude/skills/animate-illustration
```

Then open the skill's `SKILL.md` for its one-time setup.
