Don't open this before you've done the review yourself. This folder lists every failure mode deliberately placed in `../traces.jsonl`, with which traces show it, how often, what it costs the business and how severe it is, plus the list of traces that are clean or genuinely ambiguous. It exists so learn mode can compare your notes against it afterwards. If you read it first, you'll find the failures we planted instead of learning to see the ones in your own data, and that's the skill this dataset is meant to build.
